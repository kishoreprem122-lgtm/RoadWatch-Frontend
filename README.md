## 🚀 Run Locally

```bash
npm install
npm run dev
```

Set `VITE_API_URL=http://localhost:5000` in a `.env` file.

## 🛠️ Tech Stack

- React 19 + Vite
- Deployed on Vercel
- Backend: Node.js + Express on Render
- Database: Neon PostgreSQL
